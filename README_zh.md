# Sora2API 接入与价格说明

此服务与 Crazyrouter 的计费页面独立。使用前请在 Sora2API 控制台确认当前每次生成费用、额度单位、失败任务处理及服务条款。旧版固定 $0.01、10 credits 和自动退款承诺已撤下。

Updated / 更新：2026-10-12. Sora2API is a third-party service, not an official OpenAI product. A reachable page does not verify generation quality, availability or price.
